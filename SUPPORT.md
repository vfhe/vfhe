# Support

## Getting help

- Usage questions and discussion: [Zulip](https://vfhe.zulipchat.com).
- Bugs and feature requests: [GitHub issues](https://github.com/vfhe/vfhe/issues).
- Security reports: privately, per [SECURITY.md](SECURITY.md); never a public issue.

## Supported versions

VFHE is **pre-release** software (`0.x`). Only the **latest release** on
[PyPI](https://pypi.org/project/vfhe/) is supported: it receives bug fixes and
security updates. Earlier versions receive neither; there are no long-term
support or maintained back-branches, and every `0.x` release may contain
breaking changes.

A version stops receiving security updates as soon as a newer release
supersedes it. Upgrading to the latest release is the supported remediation
path for any fixed issue.

This policy will be revised at the first stable (`1.0`) release.
