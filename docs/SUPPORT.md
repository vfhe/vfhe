# Support

## Getting help

- Bugs and feature requests: [GitHub issues](https://github.com/vfhe/vfhe/issues).
- Questions about the library: the maintainers, at <maintainers@vfhe.ai>.
- Security reports: privately, per
  [SECURITY.md](https://github.com/vfhe/vfhe/blob/main/docs/SECURITY.md); never a
  public issue.
- Conduct reports: <conduct@vfhe.ai>, per the
  [Code of Conduct](https://github.com/vfhe/vfhe/blob/main/docs/CODE_OF_CONDUCT.md).

## Supported versions

Which versions receive fixes is defined in one place: the
[security policy](https://github.com/vfhe/vfhe/blob/main/docs/SECURITY.md#supported-versions).
In short: pre-release (`0.x`), latest release only.
